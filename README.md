# AudioFeatureAnalysis

This is a public showcase for Project 1 in Math 237.

In this showcase, we analyze a spotify dataset, specifically investigating song popularity.
We evaluate a songs popularity through the audio features supplied in the dataset, and compare them
across all songs, by genre, and by artist.
